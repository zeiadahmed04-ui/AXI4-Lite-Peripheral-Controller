# AXI4-Lite-Peripheral-Controller
This project is intentionally smaller than a complete AXI4 system but still requires correct handling of five independent channels (AW, W, B, AR, R), VALID/READY handshakes, independent write-address and write-data arrival, backpressure, errors, reset and simultaneous read/write activity. Registers, byte strobes, interrupts and a CDC
